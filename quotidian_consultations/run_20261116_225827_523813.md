# Estimated monthly cost of JEV for article-relevance classification

I couldn't open the link, so I'm relying on the pricing you gave: **$0.042 per 1M input tokens** and **free output**. The token counts are my estimates, not JEV's own tokenizer.

## 1. Unit cost

| Metric | Value |
|---|---|
| Input price | $0.042 / 1M tokens = **$0.000000042 per token** |
| Per 1,000 input tokens | $0.000042 |
| Output price | $0 (so the label, score, or evidence tag adds nothing) |

## 2. Tokens per article

- 6,000 characters at roughly 4 characters per token is about **1,500 tokens**. This agrees with ~900–1,000 words at ~0.75 words per token, which gives ~1,200–1,350.
- JEV probably needs the dataset definition or label set along with the article, for example "tracking seizures of product X; options: evidence / not evidence / other". I assume **~300 tokens** of this per call, which is my guess.

| Scenario | Tokens per article |
|---|---|
| Low (4.5 characters per token, tiny prompt) | 1,200 |
| **Baseline (article only)** | **1,500** |
| **Realistic (article + 300-token task context)** | **1,800** |
| High (verbose or noisy text, 500-token context) | 2,500 |

## 3. Volume

## 6. What could change the number

1. **Multiple datasets.** Cost scales linearly with the number of datasets each article is checked against, unless JEV supports multiple labels in one pass or caching. At 10 datasets, the realistic scenario is about **$16/month**, and at 50 datasets about **$82/month**.
2. **Unstripped HTML or boilerplate.** Raw markup, navigation, and ads can multiply tokens 2–5×. Cleaning to the visible text, as your 6,000-character figure assumes, keeps costs at the levels above.
3. **Long articles.** A 20,000-character report is about 5,000 tokens, which is still only $0.00021 per call.
4. **Re-processing.** Re-running articles when you change the dataset definition adds a full pass each time (about $1.64 per full month of articles).
5. **Costs outside JEV.** Crawling and scraping, storage, deduplication, and human review of borderline cases will almost certainly cost more than the model calls.

## Bottom line

For 5,000 articles per week, JEV costs about **$1.40–$1.65 per month**, with a plausible range of **$1.10–$2.30**. That is roughly **$0.00008 per article**. At this price, model cost shouldn't constrain the design. You could run several datasets or labels per article, or re-classify articles, and it would still cost less than a few dollars a month.
