# Monthly cost estimate: JEV for article relevance classification

I couldn't open the linked page, so this uses the pricing you gave: **$0.042 per million input tokens** (= $0.000000042 per token) and **free output tokens**. The token counts are my own assumptions, listed below.

## 1. Assumptions

| Parameter | Value |
|---|---|
| Articles per week | 5,000 |
| Weeks per month | 52 ÷ 12 ≈ 4.33 |
| **Articles per month** | **≈ 21,667** |
| Avg. article length | 6,000 characters (~900–1,000 words) |
| Chars per token (English) | ~4, so **~1,500 tokens per article** |
| Dataset and label context per request | ~300 tokens (dataset definition, e.g. "seizures of product X", plus label options such as *evidence / not evidence / other*) |
| **Input tokens per article (base case)** | **~1,800** |
| Output tokens | Free, so $0 whatever the label/score format |

## 2. Cost per unit (base case)

| Metric | Value |
|---|---|
| Cost per token | $0.000000042 (4.2 × 10⁻⁸) |
| Cost per article | 1,800 × $4.2e-8 = **$0.0000756** |
| Cost per 1,000 articles | **$0.0756** |
| Articles per $1 | ≈ 13,200 |

## 3. Token volume and cost (base case)

| Period | Articles | Input tokens | Cost |
|---|---|---|---|
| Week | 5,000 | 9.0 M | **$0.378** |
| Month (4.33 weeks) | 21,667 | 39.0 M | **≈ $1.64** |
| Year | 260,000 | 468 M | **≈ $19.66** |

If you count only the article text (1,500 tokens, no label context), the monthly cost is about 32.5 M tokens × $0.042 = **$1.37**.

## 4. Sensitivity

| Scenario | Tokens per article | Monthly tokens | Monthly cost |
|---|---|---|---|
| Low (short/clean text, minimal prompt: 1,200 + 100) | 1,300 | 28.2 M | **$1.18** |
| **Base** | 1,800 | 39.0 M | **$1.64** |
| High (noisy text or non-English at ~3 chars/token, long label descriptions: 2,000 + 500) | 2,500 | 54.2 M | **$2.28** |

## 5. Multiplier: number of datasets

The main cost driver is how many datasets each article is checked against. If each article is scored separately for every dataset, cost scales linearly:

| Datasets per article | Monthly cost (base) |
|---|---|
| 1 | $1.64 |
| 10 | $16.38 |
| 50 | $81.90 |
| 100 | $163.80 |

If JEV lets you pass several datasets or labels in one call, or reuse the article encoding, the cost would be lower than this.

## 6. Other relevant points

- **Output is free**, so verbose outputs (scores, multi-label tags, explanations, if supported) add nothing. Cost depends only on input size.
- **Truncating or cleaning the text** (removing boilerplate, nav menus, ads, HTML) is the main way to cut cost. Trimming 20% of tokens saves about $0.33 per month at this volume.
- **Not included:**
  - Crawling and monitoring infrastructure.
  - Storage.
  - Human review of the articles tagged as evidence. This will probably be the largest real cost, since JEV's cost is a few dollars a month.
  - Any minimum fees, rate limits or tier pricing on the JEV side.
- **Tokenizer differences:** JEV's tokenizer may count differently from the 4-chars-per-token rule of thumb. Run a sample of 100 articles to get the true average and replace the 1,800 figure.

## Bottom line

At 5,000 articles per week against a single dataset, JEV would cost roughly **$1.60 per month**, about **$0.000076 per article**. A realistic range is **$1.20–$2.30**, and the cost grows only with the number of datasets or labelling passes you run per article.
