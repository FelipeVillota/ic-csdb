# Estimated monthly cost of JEV for article-to-dataset classification

I couldn't open the link, so this uses the pricing you gave: **$0.042 per million input tokens** and **free output**. Token counts are estimates, and JEV's own tokenizer may count differently.

## 1. Assumptions

| Parameter | Value | Notes |
|---|---|---|
| Articles per week | 5,000 | Given |
| Weeks per month | 4.33 | 52 ÷ 12 |
| Articles per month | about 21,667 | |
| Characters per article | 6,000 | About 900–1,000 words |
| Characters per token | about 4 | Typical for English; gives about 1,500 tokens per article |
| Dataset prompt overhead | about 300 tokens | Dataset definition, label options (evidence / not evidence / other), e.g. "seizures of product X" |
| **Input tokens per decision** | **about 1,800** | 1,500 article + 300 context |
| Output tokens | Negligible and free | A label or score costs nothing |

## 2. Cost per token

| Unit | Cost |
|---|---|
| Per million input tokens | $0.042 |
| Per 1,000 input tokens | $0.000042 |
| Per single input token | $0.000000042 |
| Output token | $0 |

## 3. Total tokens and cost (base case)

| Period | Articles | Input tokens | Cost |
|---|---|---|---|
| Per article | 1 | 1,800 | $0.0000756 |
| Per 1,000 articles | 1,000 | 1.8M | $0.0756 |
| **Per week** | 5,000 | 9.0M | **$0.378** |
| **Per month** | about 21,667 | about 39.0M | **about $1.64** |
| Per year | about 260,000 | about 468M | about $19.66 |

## 4. Sensitivity scenarios (monthly)

| Scenario | Tokens per decision | Monthly tokens | Monthly cost |
|---|---|---|---|
| Lean (about 1,300 article tokens + 200 prompt) | 1,500 | 32.5M | **$1.37** |
| **Base** | 1,800 | 39.0M | **$1.64** |
| Heavy (messy HTML, non-English, or a long dataset definition: about 2,000 + 500) | 2,500 | 54.2M | **$2.28** |

Even with generous assumptions, the cost stays at a few dollars a month.

## 5. Scaling with multiple datasets

If each article is checked against several datasets, the context is re-sent each time. Cost scales roughly linearly, assuming the article is re-sent for each check:

| Datasets checked per article | Monthly cost (base case) |
|---|---|
| 1 | $1.64 |
| 5 | $8.19 |
| 10 | $16.38 |
| 50 | $81.90 |

If JEV can score one article against several labels or datasets in a single call, the cost would be lower than this table shows.

## 6. Other useful metrics

- **Cost per relevant item.** If about 2% of articles are true evidence (about 433 per month), the screening cost is about **$0.0038 per relevant article**.
- **Cost per million articles:** about $75.60.
- **Comparison with an LLM.** An LLM at an illustrative $0.15 per million input tokens and $0.60 per million output tokens would cost about $5.85 per month for input alone, plus output. JEV is about 3.5× cheaper on input and has no output cost. For frontier LLMs at $2–$15 per million tokens, JEV is roughly 50–350× cheaper.
- **Practical headroom.** At this price you could re-run classification whenever a dataset definition changes. Re-processing a 6-month backlog of about 130,000 articles would cost about **$9.83**.

## 7. Costs not included

- Scraping and monitoring infrastructure, storage, and text extraction or cleaning
- Human review of borderline or positive cases, which will probably be the dominant cost
- Any JEV minimum fees, rate limits, or context-length limits. If articles exceed the context window and need chunking, token counts rise.
- Tokenizer differences, so verify the actual token counts on a sample of 100 articles

## Bottom line

For 5,000 articles per week, JEV costs about **$1.64 per month** (range $1.37–$2.28). That is about $0.38 per week, or less than $0.0001 per article decision. Cost would only become meaningful if you screen each article against dozens of datasets, and even then it would be under about $100 per month.
