# Monthly cost estimate: JEV for article-to-dataset classification

I haven't opened the linked page, so this uses the pricing you gave: **$0.042 per million input tokens** and **free output tokens**.

## 1. Unit cost

| Item | Value |
|---|---|
| Input price | $0.042 / 1M tokens |
| Per 1,000 tokens | $0.000042 |
| Per single token | $0.000000042 (4.2 × 10⁻⁸) |
| Output price | $0 |

## 2. Assumptions

| Parameter | Assumption |
|---|---|
| Articles per week | 5,000 |
| Weeks per month | 52 ÷ 12 ≈ 4.33 |
| Articles per month | ≈ 21,667 |
| Article length | 6,000 characters, about 900–1,000 words |

## 6. Multiple datasets

If each article is checked against several datasets, each with its own definition, the cost scales roughly linearly, because the article is re-sent each time unless the tool supports caching or multi-label evaluation.

| Datasets per article | Monthly cost (base case) |
|---|---|
| 1 | $1.64 |
| 5 | $8.19 |
| 10 | $16.38 |
| 50 | $81.90 |

## 7. Other metrics

- **Output cost:** $0, so the cost does not change if you request labels, confidence scores, or multi-class tags.
- **Cost per evidence article found:** if about 5% of articles qualify (about 1,083 per month), the cost is roughly **$0.0015 per positive**. This is negligible next to the cost of human review.
- **Comparison with an LLM:** at an illustrative $0.15 / MTok input plus paid output, the same workload would cost several times more. Check current prices before relying on this.
- **Break-even:** one minute of analyst time costs far more than a month of JEV for this workload.

## 8. Caveats

- Token counts depend on JEV's tokenizer. Test with a sample batch to calibrate.
- Non-English text, or text with many URLs or numbers, tokenizes less efficiently and can raise the count by 30–100%.
- The estimate excludes crawling or monitoring, storage, engineering, and human QA of borderline cases. These will likely dwarf the inference cost.
- Check for minimum spend, rate limits, or batch discounts on the vendor's pricing page.

**Bottom line:** at 5,000 articles per week, JEV costs about **$1.64 per month** (a realistic range of $1.20–$2.30), or about $0.08 per 1,000 articles.
