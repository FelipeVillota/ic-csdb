# Monthly cost estimate: JEV for article-to-dataset classification

I couldn't open the linked page, so this uses the pricing you gave: **$0.042 per million input tokens** and **free output**. The token counts per article are my assumptions, and you should check them against JEV's actual tokenizer and request format.

## 1. Pricing

| Item | Price |
|---|---|
| Input | $0.042 / 1M tokens = **$0.000000042 per token** |
| Output | $0 |
| Cost per 1,000 input tokens | $0.000042 |

## 2. Volume assumptions

- Articles per week: 5,000
- Weeks per month: 52 / 12 ≈ 4.33
- **Articles per month: ≈ 21,667**
- Average article length: 6,000 characters (about 950 words)
- English text averages about 4 characters per token, so an article is **about 1,500 tokens**. This is cross-checked by 950 words × ~1.3–1.5 tokens per word ≈ 1,250–1,400.
- Task overhead per request: about 300 tokens for the dataset definition, the label options (such as "evidence", "not relevant", "other"), and any instructions. This is an assumption.

**Baseline: 1,800 input tokens per article.** Output cost is $0, so only input matters.

## 3. Baseline calculation

| Metric | Value |
|---|---|
| Tokens per article | 1,800 |
| Tokens per week (5,000 articles) | 9.0M |
| **Tokens per month (21,667 articles)** | **≈ 39.0M** |
| Cost per article | 1,800 × $0.000000042 = **$0.0000756** |
| Cost per 1,000 articles | **$0.076** |
| Cost per week | 9.0 × $0.042 = **$0.378** |
| **Cost per month** | 39.0 × $0.042 = **≈ $1.64** |
| Cost per year | ≈ $19.66 |

## 4. Sensitivity scenarios

| Scenario | Tokens/article | Monthly tokens | Monthly cost |
|---|---|---|---|
| Lean (article only, no prompt overhead) | 1,500 | 32.5M | **$1.37** |
| **Baseline** | 1,800 | 39.0M | **$1.64** |
| Heavy (noisy HTML, non-English text, long label definitions) | 2,500 | 54.2M | **$2.28** |
| Very heavy (4,000 tokens, with boilerplate and long context) | 4,000 | 86.7M | **$3.64** |

## 5. Multiple datasets

If each article is scored against several datasets (say seizures of a product, plus other topics), the cost scales roughly linearly, assuming the article is re-sent each time:

| Datasets per article | Monthly cost (baseline) |
|---|---|
| 1 | $1.64 |
| 5 | $8.19 |
| 10 | $16.38 |
| 50 | $81.90 |

If JEV lets you put several labels or datasets in one call, the cost would be much lower than this.

## 6. Other metrics

- **Throughput:** about 5,000 articles per week is roughly 0.5 articles per minute averaged over the week, trivial for any system.
- **Cost per positive:** if about 5% of articles qualify as evidence, that is about 1,083 positives per month, so **≈ $0.0015 per evidence article** at baseline.
- **Comparison with an LLM:** with the same 39M input tokens, a small LLM at $0.15/MTok would cost about $5.85 plus output charges. A mid-tier model at $3/MTok would cost about $117 plus output. JEV is roughly 3.5× to 70× cheaper on input alone, and its output is free, which matters because LLM output tokens cost several times more than input.

## 7. Costs not included

- Crawling or monitoring, and text extraction (stripping HTML boilerplate cuts tokens)
- Storage and infrastructure
- Human review of borderline or positive items
- Retries, re-scoring, or reprocessing of backlogs
- Any minimums, rate-limit tiers, or hosting fees on JEV's side

## Bottom line

At 5,000 articles per week, JEV classification costs about **$1.64 per month** (a realistic range of $1.40–$3.60), or about **$0.076 per 1,000 articles**. The cost is negligible compared with crawling, review, and engineering time, so the decision should rest on accuracy and recall for your dataset definitions, not on price.
